## Entry overview

A single-line out-of-office email auto-reply with a dry corporate twist on workplace emergencies—written to read naturally as a real away message, land on the first read, and stay concise without relying on standard beach or inbox clichés.

## Run it

Requires Node.js 22+ (the grader runs `node /bot/main.ts` with no third-party dependencies):

```bash
node main.ts
```

By default, the program writes the UTF-8 reply to `/output/entry.txt` (overridable via `MAKEFUN_OUTPUT_DIR`).
